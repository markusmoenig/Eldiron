# Eldiron CJK font data

This crate supplies the second part of the unmodified Noto Sans CJK Regular
collection from [Noto Sans CJK 2.004](https://github.com/notofonts/noto-cjk/tree/Sans2.004).
TheFramework joins the two parts at compile time to keep each crate within the
registry's compressed size limit. The complete collection has SHA-256
`b76b0433203017ca80401b2ee0dd69350349871c4b19d504c34dbdd80541690a`.

The font data is distributed under the SIL Open Font License 1.1.
