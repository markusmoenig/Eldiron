# eldiron-ruleset

Bundled official Eldiron rulesets plus validation and query helpers.

The official visual library includes editable MZ body/item geometry, clothing
materials and 32×32 item icons with project-palette bindings. Action/UI PNG
artwork and bitmap avatars remain supported. The runtime gameplay graph is
separate from those appearance recipes. See the
[official package README](rulesets/eldiron/v1/README.md) and
[Appearance guide](../../docs/docs/characters_items/appearance.md).
